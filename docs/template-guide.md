# Template Guide

This file is retained as a project documentation reference.

The official submission template requires the repository to contain:

- `submission.yaml`
- `README.md`
- `src/`
- `docs/problem-statement.md`
- `docs/solution-overview.md`
- `docs/architecture.md`
- `docs/setup-guide.md`
- `demo/`
- `presentation/`
- `CONTRIBUTING.md`
- `.gitignore`
- `.github/workflows/validate.yml`

Do not delete or rename the required top-level template files. Do not modify the automated validation workflow.

The final project-specific documentation must describe the actual implemented application rather than planned features that were not built.
